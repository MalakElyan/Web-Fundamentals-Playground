A structured collection of practical web development exercises, UI components, and assignments covering core **HTML5 semantic structure**, **CSS3 layout techniques** (Flexbox, Float, Positioning), **animations**, and **responsive designs**.

---

## 📂 Repository Index & Project Breakdown

### 🎨 1. Mini-Projects & UI Pages
* 📁 **`yokos-kitchen-landing-page/`** — A styled landing page for a kitchen/restaurant concept.
* 📁 **`Quiz-Platform/`** — User interface components for a quiz platform.
* 📁 **`html_card/`** — Customized UI card layouts.
* 📁 **`transaction/`** — Transaction & invoice UI components.

### 📐 2. CSS Layouts & Mechanics
* 📁 **`flex/`** — Hands-on exercises exploring CSS Flexbox properties and alignment.
* 📁 **`float/`** — Classic CSS float-based multi-column layout practice.
* 📁 **`Absolute Positioning&Layouts/`** — Mastering `absolute`, `relative`, and `fixed` positioning mechanics.

### 🎬 3. CSS Animations & Interactive Components
* 📁 **`CSS Keyframe Animations & Multi-Layered Motion/`** — Keyframe-based CSS animations and motion transitions.
* 📁 **`CSS Navigation Bars & Hover Effects/`** — Responsive navigation menus, dropdowns, and hover states.

### 📄 4. HTML Structure & Form Fundamentals
* 📝 **`form.html`** — Comprehensive HTML5 forms, input types, and accessibility attributes.
* 📊 **`tabel1.html` to `tabel4.html`** — HTML table structures, cell merging (`colspan`/`rowspan`), and styling.

---

## 🛠️ Technologies & Concepts

* **HTML5:** Semantic elements, forms, accessibility, tables, and media.
* **CSS3:** Box model, Flexbox, Float, Absolute/Relative positioning, Keyframes, Transitions, Pseudo-classes.
